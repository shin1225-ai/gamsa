# 감사 일기 (Open Gratitude Journal)

누구나 무료로 쓰는 감사 일기장입니다. 회원가입이 없고, 기록은 **내 기기의 브라우저에만** 저장됩니다.

## 할 수 있는 것
- 매일 감사한 일 3가지 이상과 일기 쓰기 (쓰는 동안 자동 저장)
- 할 일 적고 체크하기, 앞으로의 날짜에 할 일 미리 적기, 다가오는 할 일 D-day 보기
- 일기에 쓴 낱말에 맞춰 오늘의 성경 말씀 보기 (한글·영어 함께)
- 달력으로 지난 기록 보기, 검색, 텍스트·백업 파일 내려받기, 백업 불러오기
- 한국어 / English 화면

## 휴대폰에서 앱처럼 쓰기
- 아이폰(Safari): 공유 버튼 → "홈 화면에 추가"
- 안드로이드(Chrome): 오른쪽 위 ⋮ → "홈 화면에 추가" 또는 "앱 설치"

## 개인정보
- 일기·감사·할 일은 이 기기의 브라우저(localStorage)에만 저장되며, 어떤 서버로도 보내지 않습니다.
- 그래서 **기기를 바꾸거나 브라우저 기록을 지우면 사라질 수 있습니다.** 한 달에 한 번 [모아보기 → 백업 파일 받기]를 해 두고, 새 기기에서 [백업 불러오기]로 옮기세요.
- 마지막 백업(또는 첫 기록) 후 30일이 지나면 화면 위에 백업 알림이 뜹니다. [나중에]를 누르면 3일 뒤 다시 알려 줍니다.
- 이 페이지가 외부에서 불러오는 것은 글꼴(Google Fonts)뿐입니다.
- 앱을 열면 별이 뜬 밤하늘에서 그리스도의 얼굴로 천천히 다가가는 첫 화면이 나옵니다(하루 첫 실행은 약 5초, 그 뒤로는 짧게). 화면을 누르면 건너뜁니다. 기기에서 '동작 줄이기'를 켜 두면 첫 화면 없이 바로 열립니다.

## 성경 본문 출처
- 한글: **개역한글**(대한성서공회). 공회 저작권 안내에 따르면 성경전서 개역한글판의 저작재산권 보호기간은 2011년 12월 31일 소멸했습니다. (https://www.bskorea.or.kr/bbs/content.php?co_id=subpage2_3_4_1 , 2026-11-26 확인)
- 영어: **King James Version**(1769, 공유 저작물). 공개 데이터 2종을 글자 단위로 대조했습니다.
- 감정별 50구절 목록: [`verses.json`](verses.json)

## 그림 출처
